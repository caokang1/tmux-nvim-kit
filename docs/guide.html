tmux-nvim-kit 使用指南

按 IDEA 的习惯看 Java 项目：跳转、查用法、Spring 接口、MyBatis、配合 Claude Code。下面按"想做什么 → 按什么"列出，按键都是 Windows 版 IDEA 的默认键位。

开始 tmux 前缀 跳转 搜索 Spring / MyBatis 看代码 书签 Markdown 配合 Claude 其他 按键没反应

开始使用

按 README 安装完成后，在 tmux 里打开项目即可。Windows Terminal 用户先运行一次 windows\wt-keys.ps1，Ctrl+Shift+字母 等按键才能用。

1. 进入 tmux，打开项目

在项目根目录（pom.xml 那层）运行 nvim .

2. 等项目导入完

状态栏右侧黄色的 项目导入中 xx% 消失后，跳转、查用法才完整可用。大项目 1～3 分钟，只有第一次慢。

3. 记不住就按 F1

打开中文帮助，会按当前所在窗口列出能做的操作。按 空格 稍等也会弹出中文按键菜单。

t code                 # 进入 code 会话
cd ~/project/你的项目
nvim .

tmux 前缀变了 重要

为了让 Ctrl+B 在 nvim 里单按就能跳转，tmux 前缀按面板区分：

所在面板tmux 操作（分屏、切窗口…）用
nvimCtrl+Space 作前缀。Ctrl+B 交给 nvim 跳转到声明
shell、Claude Code 等其他面板Ctrl+B 或 Ctrl+Space 都可以，和以前一样
Claude Code 里想用它自己的 Ctrl+B（转后台）连按两次 Ctrl+B

记不住 tmux 按键时按 前缀 ?，弹出中文速查表。

跳转与查用法

多个结果时弹出列表加大预览，↑/↓ 选，回车跳，Esc 关。

想做什么按键
跳到声明Ctrl+B或Ctrl+点击
看谁用了这个方法 / 类光标已经在声明上时，Ctrl+B 直接列出用法Ctrl+B（在声明处）或Alt+F7 底部面板或Ctrl+Alt+F7 弹框
接口跳到实现类 / 抽象方法跳到实现Ctrl+Alt+B在 @Autowired 字段上也能用
跳到父类 / 接口里的这个方法Ctrl+U
点行号旁的图标跳转↓ 有实现 / 子类，↑ 实现了接口或重写了父类鼠标点击图标；空格 u O 开关图标
类型层级（父类、子类树）Ctrl+H
调用层级（谁调了它 / 它调了谁）Ctrl+Alt+H
底部树形面板里操作→/← 展开折叠，回车跳转，Alt+S 切换方向
上 / 下一个用法Ctrl+Alt+↑ / Ctrl+Alt+↓
跳回刚才的位置 / 再前进Ctrl+Alt+← / Ctrl+Alt+→

跳进依赖库的类时，标签页显示类名（如 ArrayList.class），状态栏显示所在 jar；在库里也能继续 Ctrl+B、查用法。

搜索

想做什么按键
什么都搜（类、文件、方法、操作）代替 IDEA 的双击 ShiftCtrl+Shift+Space或空格 s e
找类Ctrl+N，默认只搜项目；再按一次包含依赖库
找文件Ctrl+Shift+N
全局搜索文字Ctrl+Shift+F；选中文字后按直接搜它
全局搜索里限定范围整个项目 → 当前模块 → 当前目录 → 自选目录，范围显示在标题Alt+S 切换范围，Alt+T 排除测试代码
全局搜索里的开关Alt+C 区分大小写，Alt+W 整词，Alt+X 正则；只搜某类文件：输入 关键字 -- -g *.java
全局替换Ctrl+Shift+R
当前文件的结构（方法、字段）Ctrl+F12；弹框里再按一次 Ctrl+F12 显示继承来的成员
最近打开的文件Ctrl+E

Spring / MyBatis

这几项不依赖项目导入，打开项目马上能用。

想做什么按键
按接口地址找 Controller 方法输入路径片段如 user/li；常量拼出的地址也能解析，Feign 接口标 [Feign]Ctrl+\或空格 s U
Mapper 接口方法 ↔ XML 里的 SQL在方法名或 id="..." 上按 Ctrl+B
XML 里跳到 resultMap、include 的 sql 片段、实体类在 resultMap="..."、refid="..."、resultType="..." 上按 Ctrl+B
yml / properties 配置项 → Java 里哪里用了它包括 @Value 和 @ConfigurationProperties 的字段在配置键上按 Ctrl+B或Alt+F7
@Value("${...}") → 配置文件里的定义多个 profile 都有时列出来让你选Ctrl+B

看 Java 代码

折叠用 Alt 而不是 IDEA 的 Ctrl，因为 Ctrl+-/Ctrl+= 留给终端缩放字体。

想做什么按键
折叠 / 展开当前块打开文件时 import 已经自动折叠；Javadoc 也能折Alt+- / Alt+=
折叠 / 展开全部方法体Alt+Shift+- / Alt+Shift+=
看这一行是谁、什么时候改的Alt+Shift+G 打开 Git 注释栏，再按关闭；在注释栏上回车看那次提交的改动
文件树把单层子目录的包合并显示（com/example/demo）默认打开，空格 u P 开关
.properties 里的 用户 显示成中文自动；文件内容不变，编辑时光标行显示原文

书签

按项目保存，下次打开还在。用 Alt+F11 是因为 F11 留给终端全屏。

想做什么按键
在当前行加 / 去掉书签Alt+F11
加带字母或数字的书签Ctrl+F11，再按一个字符
跳到带字符的书签空格 m 加那个字符
所有书签列表Alt+Shift+F11

Markdown

想做什么按键
打开链接相对路径文件、#标题、文件.md#标题、网址都可以回车或Ctrl+B或Ctrl+点击
标题大纲，输入过滤后跳转Ctrl+F12或Alt+7
渲染效果 ↔ 源码空格 u m；按 i 编辑时自动显示源码

配合 Claude Code

推荐布局：前缀 % 左右分屏，左边 nvim 看代码，右边运行 claude。

想做什么按键
Claude 输出或日志里提到的 文件:行号、Java 异常堆栈，在左边 nvim 打开在 Claude 面板按 前缀 j，选一条回车
把选中的代码发给 Claude以 @文件#L起-止 加代码贴进输入框，不会自动发送nvim 里选中后按 空格 a s
粘贴一段堆栈 / 日志，解析成可跳转的列表nvim 里 空格 j s

其他

想做什么按键
复制引用可选 相对路径:行号、com.example.Foo#bar、文件名等，复制到系统剪贴板空格 c y或Ctrl+Alt+Shift+C
中文帮助F1或空格 h；帮助里按 a 看全部按键

按键没反应时

情况怎么办
Ctrl+Shift+字母、Ctrl+Shift+Space 在 Windows Terminal 里没反应运行一次 windows\wt-keys.ps1（不需要管理员，见 README「Neovim」一节）
Ctrl+Shift+字母 按不出来对应的 Alt+Shift+字母 功能完全相同，例如 Alt+Shift+F 全局搜索
Ctrl+Alt+Shift+C 变成了"提取常量"终端分不清这两个键，用 空格 c y
跳转、查用法没结果看状态栏是否还在"项目导入中"，等它消失
在浏览器里用浏览器会抢走 Ctrl+N、Ctrl+W、Ctrl+T；Ctrl+N 用 Alt+N 代替，千万别按 Ctrl+W
文件树显示不对（插件升级后）空格 u P 关掉包合并
完整按键表见仓库 README；nvim 里 F1 的中文帮助总是和当前版本一致。
